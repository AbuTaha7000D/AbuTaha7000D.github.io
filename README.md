## Live Site

<https://abutaha7000d.github.io/portfolio/>

## Run Locally

No build tools required. Open `index.html` in a browser, or use a local server:

```bash
# Python
python3 -m http.server 8000

# Node.js (npx)
npx serve .
```

Then visit `http://localhost:8000`.
